# Password Reset Guide — Felix
# For Windows PCs where you can't log in

============================================================
## WHEN TO USE THIS
============================================================

Client says: "I forgot my Windows password. Can you help?"

You CAN help IF:
- It's a home or small office PC
- No BIOS password (or client knows it)
- No full disk encryption (BitLocker)

You CANNOT help IF:
- BIOS password is set and unknown
- Full disk encryption is on
- Physical damage to USB ports

============================================================
## WHAT YOU NEED
============================================================

1. USB stick (8GB or larger)
2. Ubuntu ISO file (download from ubuntu.com)
3. A computer to prepare the USB
4. Tool to write ISO to USB:
   - Rufus (Windows)
   - Etcher (cross-platform)
   - dd command (Linux)

============================================================
## HOW TO MAKE THE LIVE USB (Rufus on Windows)
============================================================

1. Download Ubuntu ISO from ubuntu.com
2. Download Rufus from rufus.ie
3. Plug in USB (will be erased)
4. Open Rufus
5. Select USB under "Device"
6. Click "SELECT" → choose Ubuntu ISO
7. Click "START"
8. Confirm warning (data will be erased)
9. Wait ~10 minutes
10. When it says "READY", close Rufus

Your USB is now a Live USB. Ready for password resets.

============================================================
## HOW TO RESET THE PASSWORD (on-site)
============================================================

Setup:
- Plug USB into the target PC
- Restart the PC

1. Press boot menu key during startup:
   - Common keys: F12, F2, F9, Esc, Del
   - Dell: F12 | HP: F9 | Lenovo: F12 | Acer: F12

2. Boot menu appears → choose USB

3. Ubuntu loads (no password needed)

4. Open Terminal (Ctrl+Alt+T)

5. Find the Windows disk:
   lsblk
   (look for the largest partition, like sda1 or sda2)

6. Mount the Windows disk:
   sudo mkdir /mnt/windows
   sudo mount /dev/sda1 /mnt/windows

7. Go to System32:
   cd /mnt/windows/Windows/System32
   (if not there, check case: Windows/System32)

8. Backup utilman.exe:
   sudo mv utilman.exe utilman_backup.exe

9. Copy cmd.exe to utilman.exe:
   sudo cp cmd.exe utilman.exe

10. Unmount and reboot:
    cd ~
    sudo umount /mnt/windows
    sudo reboot
    (remove USB when PC restarts)

11. Windows starts → login screen

12. Click the accessibility icon (bottom right)
    (looks like a small clock or accessibility symbol)
    → Command Prompt opens as SYSTEM

13. Reset the password:
    net user Felix newpass123
    (use quotes if the username has spaces: "John Doe")

14. Log in with new password ✅

15. CLEAN UP:
    - Boot Ubuntu again (or use admin account)
    - Restore utilman:
      sudo mv utilman_backup.exe utilman.exe
    - Reboot

## IMPORTANT COMMANDS CHEAT SHEET
============================================================

lsblk                    # list disks and partitions
sudo mount /dev/sda1 /mnt/windows    # attach Windows disk
cd /mnt/windows/Windows/System32      # go to system folder
sudo mv utilman.exe utilman_backup.exe    # rename utilman
sudo cp cmd.exe utilman.exe               # copy cmd as utilman
sudo umount /mnt/windows     # detach Windows disk
sudo reboot                  # restart PC
net user Felix newpass123    # reset password in Windows

============================================================
## ALTERNATIVE: sethc.exe METHOD
============================================================

If utilman doesn't work, use sethc.exe:

sudo mv sethc.exe sethc_backup.exe
sudo cp cmd.exe sethc.exe

At login screen:
- Wait for it to fully load
- Press Shift 5 times quickly
- Command Prompt opens as SYSTEM
- Use `net user` the same way

## COMMON PROBLEMS
============================================================

Problem: Boot menu doesn't open
- Wrong key. Try F1, F2, F10, F12, Esc, Del.
- Some PCs need you to hold Fn first.

Problem: BIOS password prompt appears
- Stop. Ask client. If unknown → can't continue.

Problem: Ubuntu boots but Windows disk won't mount
- Disk may be encrypted (BitLocker)
- Or wrong partition (try sda2, sda3, etc.)

Problem: utilman doesn't open cmd after reboot
- Windows may have auto-repaired
- Try again, or use sethc.exe method

Problem: Windows refuses to boot after swap
- You swapped wrong file. Boot Ubuntu, restore backup.
- sudo mv utilman_backup.exe utilman.exe
